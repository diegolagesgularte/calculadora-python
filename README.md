# Projeto: Calculadora em Python

## Objetivo do Projeto
Desenvolver uma calculadora simples em Python para realizar operações básicas (soma, subtração, multiplicação e divisão).  
Esse projeto foi criado como exercício acadêmico para praticar lógica de programação.

---

## Tecnologias Utilizadas
- Python 3  
- VS Code  
- Git/GitHub  

---

## Aprendizados
Durante o desenvolvimento, aprendi a:
- Criar funções em Python para diferentes operações.  
- Usar condicionais e laços de repetição.  
- Organizar o código de forma legível.   

---

## Como Executar
1. Clone este repositório.  
2. Execute `calculadora.py` em Python 3.  
3. Escolha a operação e insira os valores.
